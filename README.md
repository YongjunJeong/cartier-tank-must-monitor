# 🛒 까르띠에 재고 알림 봇 (Cartier Stock Monitor)

까르띠에 공식 홈페이지는 입고 시 카카오톡이나 문자 메시지 등 별도의 **재고 알림 서비스**를 제공하지 않습니다. 이로 인해 한국에서 특히 인기가 많아 구하기 몹시 힘든 **탱크 머스트 드 까르띠에 워치**와 같은 제품은 입고 일정을 매번 일일이 확인해야만 하는 번거로움이 있습니다.

이 프로젝트는 누구보다 빠르게 재고 업데이트 상태를 파악하고, 구매 타이밍을 선점하기 위해 제작된 실시간 웹 스크래핑 기반의 **자동화 모니터링 봇**입니다. 파이썬과 Headless Browser(Playwright)를 활용해 "상담원 연결" 버튼이 "쇼핑백에 추가하기"로 활성화되는 순간 즉시 Slack 메시지로 알림을 전송합니다.

## 🚀 주요 기능 (Features)

- **Headless Browser 모니터링**: Playwright를 이용해 사람의 실제 브라우저 클릭과 이동 사이클을 렌더링하고 DOM 변화를 정확하게 읽습니다.
- **리소스 최적화 (초고속 탐색)**: 시계 고화질 이미지, 불필요한 폰트나 영상 등 무거운 네트워크 리소스 다운로드를 강제 차단하여, 대기시간(`networkidle`) 자체를 무방비하게 기다리지 않는 압도적인 속도 탐지력을 제공합니다.
- **봇 탐지 우회 전략 (Anti-Bot Evasion)**: 
  - 일정한 폴링 주기 대신 무작위 대기 시간(Randomized Jitter)을 주어 사람처럼 불규칙하게 접근합니다.
  - HTTP/2를 비활성화 하거나 브라우저 채널 스와핑을 통해 IP/Bot 밴 타격을 우회합니다.
- **Slack 즉각 알림**: 스크립트 모니터링 중 특정 버튼의 활성화 이벤트를 탐지하면 즉각 설정해둔 직장/개인 슬랙 채널을 통해 재고 알림을 쏩니다.

## ⚙️ 파일 구성

저장소에는 다음 파일들이 포함되어 있습니다:
1. `common.py`: 두 스크립트가 공유하는 설정과 유틸리티(상품 URL, `.env` 로딩, Slack 알림, 브라우저/컨텍스트 생성, 리소스 차단)를 모아둔 모듈입니다.
2. `test_monitor.py`: Slack Webhook 연동 및 네트워크 세팅이 제대로 이뤄졌는지 1회용으로 테스트하기 위한 파일입니다. 무한 반복되지 않고 한 번만 구동됩니다.
3. `tank_must_monitor.py`: 실사용을 위한 메인 모니터링 봇입니다. 24시간 도는 루프를 실행하며 지터(Jitter)로 쉬는 시간을 계산해 수십 초마다 자동으로 새로고침하며 재고를 추적합니다.

## 🔧 설치 및 요구 사항 (Prerequisites)

PC에 Python 3.8 이상의 버전이 설치되어 있어야 합니다.

```bash
# 필요한 패키지 설치
pip install -r requirements.txt

# Playwright 엔진 모듈 설치 (최초 1회)
playwright install chromium
```

## 📦 실행 방법 (Setup & Run)

1. **Slack Webhook 설정 및 환경변수 등록**  
   보안을 위해 저장소의 깃(Git) 내역에 올라가지 않도록 `.env.example`을 복사해 `.env` 파일을 만들고, 본인의 Slack Webhook URL로 값을 채워줍니다.
   ```bash
   cp .env.example .env
   ```
   ```env
   # .env
   SLACK_WEBHOOK_URL="https://hooks.slack.com/services/XXX/YYY/ZZZ"
   ```
   사내 프록시 환경이라면 `HTTPS_PROXY`(또는 `HTTP_PROXY`) 환경변수를 추가로 설정하면 두 스크립트 모두 자동으로 프록시를 통해 접속합니다.

2. **환경 테스트 동작 점검 (최초 1회)**
   ```bash
   python test_monitor.py
   ```
   *정상 실행 결과: 터미널 로딩 완료 후, 슬랙 메신저에 "상담원 연결"이 감지되었다는 시그널 테스트가 날아옵니다.*

3. **연속 재고 모니터링 루프 시작**
   ```bash
   python tank_must_monitor.py
   ```
   *개인 머신이나 AWS EC2, 라즈베리 파이 같은 상시 구동 서버에 올려두시면 재고가 들어오는 찰나의 순간을 잡아냅니다!*
